# Dr. Mahmoud Abo Omar — Modern Website

نسخة مستقلة من الموقع التعريفي القديم (2024)، مع إعادة بناء الواجهة بالكامل باستخدام HTML وCSS وJavaScript دون Bootstrap أو jQuery أو أدوات بناء.

## التشغيل والنشر
- فك الضغط وافتح `index.html` في متصفح حديث، أو شغّل خادمًا محليًا من مجلد الملفات بالأمر `python -m http.server 8000` وافتح `http://localhost:8000`.
- للنشر، احتفظ بنسخة احتياطية من الموقع الحالي ثم ارفع محتويات الحزمة كاملة إلى المجلد الجذري للاستضافة. لا يتطلب الموقع خادم تطبيق أو قاعدة بيانات.
- الصور داخل `img/`، والتنسيق داخل `css/style.css`، والمنطق داخل `js/app.js`.
- يستخدم خط Cairo من Google Fonts عند توفر الإنترنت، مع خط بديل محلي.

## إعداد أرقام واتساب (مهم قبل النشر)
عدّل `js/config.js` فقط. الأرقام بصيغة دولية دون + أو مسافات.
- طنطا: 201070797157 — كان رقم اتصال طنطا وأحد رقمي واتساب في النسخة الأصلية.
- المهندسين: 201022267017 — رقم واتساب عام موجود في النسخة الأصلية، لم يكن مخصصًا لفرع معين. اختير كوجهة افتراضية للمهندسين بدل الاختيار العشوائي، ويجب تأكيده أو استبداله بالرقم المعتمد للفرع قبل نشر الموقع.
- بيانات العناوين والهواتف والتخصصات والتقييمات مأخوذة من النسخة القديمة، ولم يُتحقق من حداثتها. راجعها مع العيادة، وكذلك حق نشر صور الحالات والتقييمات.

## آلية الحجز
اختيار العيادة ونوع الزيارة والاسم والهاتف، مع اختيار التخصص والتاريخ والفترة اختياريًا. يعرض الموقع جدول مراجعة، ثم ينشئ رابط wa.me برسالة نصية منسقة على شكل صفوف. لا يدعم واتساب جدول HTML فعليًا في الرسائل. المستخدم هو من يضغط إرسال داخل واتساب؛ إرسال الطلب ليس تأكيدًا للموعد. لا توجد قاعدة بيانات أو تخزين لبيانات المرضى في الموقع.

## الاختبار
تم اختبار نسخة مجمعة داخل Chromium بأحجام 1440×900 و768×1024 و390×844 و320×740، مع التحقق من عدم وجود تجاوز عرض أفقي، وتصفية الصور، وعرضها، والقائمة على الشاشات الصغيرة، والتحقق من النموذج واختيار الفرعين وتوليد روابط واتساب. بيئة الاختبار منعت فتح عنوان الخادم المحلي والملفات مباشرة؛ لذلك جرى تضمين ملفات CSS وJS والصور في صفحة الاختبار فقط. لم يتم اختبار الاتصال الخارجي بخدمات واتساب أو Google Maps أو تحميل خط Google Fonts. لم تُرسل رسائل حقيقية ولم يتم النشر على الموقع الحي.
